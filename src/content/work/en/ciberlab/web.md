## Introduction

**CiberLab** is a cybersecurity research project led by INCIBE in collaboration with the Robotics Group, providing a web platform for analyzing and exploring malware samples.

The application allows users to submit potentially malicious files for analysis. These samples are processed using **CAPE Sandbox**, a dynamic analysis environment that collects information about malware behavior.

The resulting data is then processed to generate reports and store relevant information, which can be accessed directly through the platform.

My contribution focused on the **maintenance and enhancement of the existing web application**, adapting it to the project's evolving requirements and the additional information generated by the analysis systems.

## Architecture and Technologies

The platform uses **React** for the frontend and **Node.js with Express** for the API, with Sequelize as the ORM and MariaDB for data persistence.

The application integrates with other components of the CiberLab ecosystem responsible for sample analysis and automated report generation.

**Hugging Face** is also used as a repository for datasets and analysis results, while Docker facilitates the deployment of the application's components.

![CiberLab technical architecture](/assets/work/ciberlab/web-architecture.png)

## Development and Implementation

My work primarily involved extending the platform's capabilities for storing and retrieving malware analysis results.

The main improvements included:

- **Data model extension:** adapted the MariaDB database to store structured information about malware families, detection signatures, indicators of compromise (IoCs), and other analysis results.

- **Integration of new analysis results:** updated the application's logic to incorporate additional information provided by the sample processing systems.

- **Data visualization:** enhanced the interface to display the new information through charts and statistics.

- **Platform maintenance:** updated existing components to maintain compatibility with the project's ongoing development.

These improvements expanded the information available to users and made it easier to explore and interpret the results collected by CiberLab.

## Results

The outcome was an enhanced platform capable of storing and presenting more detailed information about analyzed malware samples.

The extended data model supports the organization of different malware indicators and characteristics, while the visualization tools make this information easier to access and interpret.

![Malware statistics visualization in CiberLab](/assets/work/ciberlab/web-graphics.png)

This project allowed me to gain valuable experience in the **maintenance and evolution of existing web applications**, particularly in data modeling, component integration, and the development of cybersecurity-oriented tools.
